# Smart Learning Analytics Platform

This project aims to design and implement a smart learning analytics system that analyzes student study behavior, predicts academic performance using machine learning, and provides personalized study recommendations.

## Motivation
Many students study without understanding how their learning habits impact academic performance. This platform bridges that gap using data-driven insights.

## Features
- Study behavior tracking
- Learning analytics dashboard
- Performance prediction using machine learning
- Personalized study recommendations

## Tech Stack
- Frontend: React
- Backend: FastAPI
- Database: PostgreSQL
- Machine Learning: Python (scikit-learn)
